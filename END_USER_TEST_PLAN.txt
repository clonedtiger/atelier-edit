1. TEST PLAN OVERVIEW & OBJECTIVES
================================================================================
The objective of this test plan is to thoroughly evaluate the end-user experience,
functional reliability, data integrity, visual rendering, and mobile responsiveness
across all modules of Atelier Edit.

Success Criteria:
- Zero horizontal overflow / lateral viewport blowout on any mobile device (375px–430px).
- Zero console exceptions or uncaught runtime rejections.
- 100% pass rate on core authentication, security, and GDPR workflows.
- Accurate AI Stylist outfit generation based on physical wardrobe pieces.
- Seamless touch navigation (≥ 44px tap targets) and iOS Safari auto-zoom prevention.

MODULE 1: USER ONBOARDING, AUTHENTICATION & SECURITY
--------------------------------------------------------------------------------

[TC-01] User Registration & Profile Initialization
- Description: Verify that a new user can register with valid credentials.
- Preconditions: Unauthenticated landing view active.
- Steps:
  1. Open http://localhost:3000.
  2. Click "Register" tab on the authentication card.
  3. Fill Name ("Helena Vance"), Email ("helena.vance@example.com"), Password ("Password123!"), Size ("UK 10"), Sex ("Female").
  4. Submit registration form.
- Expected Result: User is registered with bcrypt password hashing; default profile initialized; redirected into stylist view.

[TC-02] Secure Login & Session Cookie Handling
- Description: Verify login with valid credentials and verify session security.
- Steps:
  1. Submit login form with registered email and password.
  2. Inspect response cookies for 'auth_token'.
- Expected Result: Login succeeds (200 OK); cookie has 'httpOnly: true' and 'SameSite: Lax'; session persists on page refresh.

[TC-03] Two-Factor Authentication (TOTP MFA) Setup & Enforcement
- Description: Verify 2FA enrollment and code verification.
- Steps:
  1. In registration/profile, enable 2FA.
  2. Generate TOTP secret and QR code URI.
  3. Enter 6-digit verification code.
- Expected Result: TOTP secret encrypted and stored in DB; subsequent logins require valid 2FA code.

[TC-04] Password Recovery Code Dispatch & Reset
- Description: Verify forgot-password workflow without plain-text credential leaks.
- Steps:
  1. Click "Forgot Password" on login panel.
  2. Submit user email address.
  3. Enter 6-digit recovery code generated by backend dispatch.
  4. Submit new password ("NewSecurePass456!").
- Expected Result: Recovery code verified within 15m expiration; password reset successful; login works with new password.

[TC-05] Session Logout & Protected Route Guarding
- Description: Verify session destruction and API route authorization.
- Steps:
  1. Click "Sign Out" button in Profile or Header.
  2. Send unauthorized GET request to /api/wardrobe and /api/recommendations.
- Expected Result: Session cookie cleared; user returned to login panel; protected APIs return 401 Unauthorized.

6. KNOWN ISSUES, UI OBSERVATIONS & RECOMMENDATIONS
================================================================================
Observations & Recommended Next Steps:
1. Push Notifications & Badge Counters:
   - As requested by the user, bracket counters (x) were removed from the menu tabs to prevent user confusion without push notification triggers.
   - Future enhancement: If real-time unread alerts are desired (e.g. for new Substack RSS feed drops), integrate a subtle gold notification dot (pulsing indicator) on the "What's New" tab rather than numerical badge counters.
2. Image Optimization:
   - High-resolution luxury photography URLs load smoothly. For offline PWA support, consider caching top wardrobe thumbnails locally via service worker cache storage.
3. Touch Gesture Dragging in Studio on iOS:
   - Desktop mouse drag-and-drop works seamlessly. On touchscreens, ensure touch-action: none is applied to active canvas items to prevent page scrolling while positioning flat-lay pieces.
